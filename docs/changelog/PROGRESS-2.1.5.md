# 2.1.5（vc183，2026-10-21）

修复 2.1.4 自定义背景在全面屏手势机型（Redmi K90 / HyperOS）上的显示问题。其他功能和默认值不变。

## 自定义背景铺满全屏
- 设了背景后，背景图一直铺到屏幕最底部，手势小白条下方不再有一条不透明的色带。
- 对话页顶栏（「IRIDIS / 未加载模型」）和状态栏区域改为半透明，透明度与卡片一致，背景图不再被顶栏截断；文字仍清楚。
- 输入框仍留出导航栏高度，始终在小白条上方。

## 系统栏
- 状态栏、导航栏完全透明，关闭系统的导航栏对比度遮罩（HyperOS 否则会在小白条后加一层底色）；状态栏 / 导航栏图标深浅仍跟随主题。
- 没设背景时外观不变，只是小白条区域改为与对话页同色，不再是另一种颜色的色条。
- 设置等其他页面内容仍留出导航栏高度，不会被小白条遮住。
