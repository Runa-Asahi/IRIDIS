# 2.1.4（vc182，2026-10-21）

IRIDIS 2.2 第一步：主题。其他功能和默认值不变。

## 配色
- 外观 › 主题 新增「配色」：默认、樱花粉、薄荷绿、丁香紫、奶油黄，一排圆形色块，点选即换，选中的有勾。
- 每套配色都有浅色和深色两版，仍由 浅色 / 深色 / 跟随系统 决定用哪版。
- 整个界面一起变：页面和对话背景、卡片、气泡、强调色、开关滑块、选中文字。
- 文字对比度符合 WCAG AA（单元测试逐项检查）。默认配色不变，仍是默认。

## 自定义背景
- 外观 › 背景 ›「自定义背景」：用系统照片选择器选图，无需存储权限。
- 图片缩放到屏幕大小后存进 App 私有目录，不保留原图链接；显示在对话页后面。
- 「模糊程度」0–25 dp，「遮罩深浅」0–90%（用主题背景色盖一层，保证文字清楚），「移除背景」恢复纯色。
- 设了背景后，卡片和气泡略微透明，背景能透出来；弹窗和输入框保持不透明。
- 默认没有背景。
