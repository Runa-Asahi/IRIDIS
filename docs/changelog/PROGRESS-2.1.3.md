# 2.1.3（vc181，2026-10-20）

## 修复
- 修复：API 服务在 127.0.0.1 上连不上（开关显示运行中，浏览器却报连接被拒绝）。本机模式改为监听 IPv4 127.0.0.1，局域网模式仍为 0.0.0.0。

界面简化：常用项更少、不常用项收起，功能都还在，默认值不变。

## 模型
- GGUF 模型设置去掉「推理引擎」切换，只选后端（自动 / CPU / GPU / NPU）：NPU 用 GenieX，GPU / CPU 用内置 llama.cpp。
- GenieX 运行库没下载时，NPU 置灰并提示「需先在 设置 › 模型与后端 下载 GenieX」。
- 设置 › 模型与后端：去掉「GGUF 默认引擎」；GGUF 默认后端可选 NPU（已装 GenieX 时）。
- 旧设置自动迁移：之前选了 GenieX 的模型改为后端 NPU；全局选了 GenieX 的改为 GGUF 默认后端 NPU。
- 自动 仍是 CPU；QAIRT 包仍只用 GenieX NPU。

## 设置
- 生成：只显示「最大回复长度」「温度」，其余采样参数放进「高级」。
- 模型与后端：加载选项（Flash Attention、KV 缓存、批大小、mmap、预热）全部放进「高级」。
- 「上下文与记忆」和「记忆」合并为「记忆与上下文」一个入口、一页。
- 新增「开发者选项」（关于 IRIDIS 页底部）：资源档配置、资源诊断、运行状态机架、性能浮窗、顶栏按钮底色。
- 设置首页不再显示运行状态机架；外观页只留主题、视觉效果与反馈。
