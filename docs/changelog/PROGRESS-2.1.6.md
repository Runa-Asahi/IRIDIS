# 2.1.6（vc184，2026-10-21）

IRIDIS 2.2 计划的第 2、3 步与提示词精简合并发布：feat/composer（= feat/themes 2.1.5 + feat/render + 输入框改版）合并 feat/prompt。主题、自定义背景等 2.1.5 功能不变。

## 聊天富内容渲染（feat/render）
- 回答中的 ```html / ```svg 代码块显示为预览卡片（沙箱 WebView，禁用网络与文件访问），可切换源码。
- Markdown 图片 `![](...)` 直接显示；点开全屏查看，支持缩放、保存到相册、分享。
- web_fetch 抓取网页时一并返回页面主要图片，回答可直接引用。
- 设置新增两个开关：「渲染网页代码」「加载网络图片」。

## 输入框改版（feat/composer）
- 右侧合并为一个长条语音胶囊：点按 = 语音通话；长按 = 语音输入（按住说话，上滑取消，松开填入输入框）；输入框有文字时变为「发送」；生成中变为「停止」。
- 新增「技能」按钮：从面板选择技能或智能体工具，作为本条消息的引用（显示为 @名称 标签）；发送时只在这条用户消息后附一行 `[For this request: use skill ...]`，系统提示不变（可复用 KV 缓存）。未开启智能体模式时会先提示开启。
- 附件按钮由回形针改为「+」。

## 提示词精简与 KV 前缀复用（feat/prompt）
- 智能体系统提示重写并精简：全部工具开启时约 780 → 570 估算 token；工具按固定顺序列出，同一对话内逐字节一致。
- 计划（plan）不再写进系统提示，改为附在最新一条用户消息末尾；上下文压缩摘要不再写进系统提示，改为放在剩余历史最前。计划更新、压缩都不再让系统提示的缓存失效。
- 知识库检索片段留在所属的那条用户消息上，后续轮次不再因片段移动导致整段重新预填充。
- GGUF（llama.cpp）新建对话时保留已有 KV 缓存，与新提示的公共前缀直接复用。
- 工具说明精简；PromptBudgetTest（v230）锁定预算：智能体系统提示 ≤ 600 token。

## 合并说明
- 技能引用行与计划行共存于最新一条用户消息：先是用户原文和附件，再是技能引用行，最后是计划。
- 修复合并后的潜在问题：智能体模式下计划附在用户消息之后，图片匹配（VisionPrompt.targetIndex）原先只认完全相同或结尾相同，会导致图片发不出去；现在再按包含匹配一次。
- 新增 V216ReleaseTest（版本号、技能行 + 计划行顺序、带计划时图片仍能找到）。
